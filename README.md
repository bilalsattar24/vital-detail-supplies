# Vital Detail Supplies

Temporary landing page for **Vital Detail Supplies**, an auto detailing supply shop in Alhambra, CA. This site establishes an online presence until the full Shopify storefront is ready.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
